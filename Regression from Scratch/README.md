# Linear Regression from Scratch

Here is my attempt at building linear regression from scratch using Python. In the files My_Linear_Reg.py and My_Mult_Reg.py, I implement simple linear regression and multiple linear regression, respectively. 

In the main file [LinregTest.ipynb](LinRegTest.ipynb), I provide explanations for the math behind linear regression, and how the coefficients are calculated. I use scikit-learn to generate some random regression data, and I compare how my model compares vs. the scikit-learn one.
